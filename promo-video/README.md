## 4. 复现

```bash
# 1) 配乐（A/B）
py -3 src/audio.py --plan both

# 2) 2025 帧（Chrome Headless + CDP；约 2–3 分钟）
node src/render.mjs --all

# 3) 抽查静帧
node src/render.mjs --stills 0.9,8.4,13.5,20.5,30.2,35.6,41.6,50.0,58.4

# 4) 编码（响度两遍法的第二遍；第一遍测量值见 out/loudnorm.txt）
ffmpeg -y -framerate 30 -i frames/%05d.jpg -i out/audio_A.wav \
  -filter_complex "[0:v]scale=1080:1920:flags=lanczos:in_range=full:out_range=tv:out_color_matrix=bt709,format=yuv420p[v];[1:a]highshelf=f=8500:g=-2,loudnorm=I=-14:TP=-1.0:LRA=9:measured_I=-18.10:measured_TP=-0.75:measured_LRA=6.10:measured_thresh=-28.26:offset=0.80:linear=true,aresample=48000[a]" \
  -map "[v]" -map "[a]" -c:v libx264 -preset slow -crf 18 -profile:v high -level 4.1 \
  -pix_fmt yuv420p -colorspace bt709 -color_primaries bt709 -color_trc bt709 \
  -r 30 -g 60 -keyint_min 30 -c:a aac -b:a 192k -ar 48000 -movflags +faststart -shortest \
  out/shiye_promo_60s.mp4
```

预览：直接打开 `src/index.html`（无 `?export=1` 时按实时 RAF 播放，可拖动进度条）。导出模式必须带 `?export=1`，由 `render.mjs` 逐帧调用 `window.__renderAt(t)`；任意帧可 seek，固定 seed 20261112。
