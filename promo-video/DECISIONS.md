# DECISIONS — 拾页 60s 抖音介绍片

日期：2026-11-12
作者当次要求（最高优先级）：

- 用 `fy-code-animation` 做 60s 左右介绍视频。
- 风格与 `AI小说阅读器` 的 UI 类似，古风。
- 字体由执行者选择，需适配。
- 手机抖音竖屏比例（1080×1920，9:16）。
- 速度稍快，视觉效果与动效华丽，字号大、可读性强。
- 功能介绍全面；允许适度夸张，符合抖音平台风格。
- 预算不设限，尽可能精美。

执行者据此确定的项目决定：

1. **画风**：全片统一“宣纸水墨 + 鎏金 + 朱砂”的古风系统，材质与色温对齐应用 `paper` 主题（#F7F4EC / #2A2A28 / #8A6A4F），不逐段换画风。依据：产品介绍需要统一识别；作者已委托字体与风格细节。
2. **字体**：正文与 UI 用 Noto Serif SC（应用 serif 栈的同一字族，OFL 许可，随工程内置）；大字标题与印章用系统楷体（KaiTi/STKaiti，应用本身提供“楷体”阅读字体，属于既定字体体系）。不引入第三种风格化手写体。
3. **画幅与帧率**：1080×1920，30fps，60.0s，H.264，AAC 立体声。
4. **引擎**：单文件 HTML + Canvas 2D，`render(t)` 纯函数，固定 seed，无 `Date.now`、无逐帧累计状态；Chrome Headless 逐帧截图，ffmpeg 编码。理由：字体/排版可控、无额外依赖、任意帧可复现。
5. **声音**：原创程序化配乐（古筝、琵琶、箫、太鼓、电子脉冲、金铃）+ 音效，112 BPM，D 小调；不采样第三方音乐。写作四案，成片采用 A 案，B 案作为备选音频一并交付。
6. **界面素材**：应用 UI 为按源码设计令牌重绘的“界面示意”，不是 Electron 实机录屏；不宣称真实延迟、真实用户数据或真实下载量。文案中的“预写 1–3 章”对应源码 `bufferMin/Max=1..3`。
7. **贯穿对象**：一卷自下而上的宣纸卷轴；每次转场由墨迹吞没/纸张翻过完成，最后卷轴收拢为“拾”字印章。
8. **阶段**：用户明确要求成片，按 `final` 执行；同时保留任务卡、源码、帧序列、音频工程和检查记录，便于交接与返修。
